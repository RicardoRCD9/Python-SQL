# Python + MySQL

Projeto desenvolvido em Python com integração ao MySQL para cadastro e consulta de jogos concluídos.

## Tecnologias utilizadas

- Python
- MySQL
- mysql-connector-python
- python-dotenv

## Funcionalidades

- Conexão com banco de dados MySQL
- Consulta de jogos cadastrados
- Exibição dos jogos no terminal
- Cadastro de novos jogos
- Registro de horas jogadas
- Registro de obtenção de platina
